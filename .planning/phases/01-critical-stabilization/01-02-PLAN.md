Fix the document parsers to preserve structural line breaks so resume section segmentation succeeds, and add comprehensive unit tests verifying parser behavior.

</objective>

  <action>
    In `server/utils/pdf_parser.py` and `server/utils/docx_parser.py`:
    Replace the blanket whitespace collapse `re.sub(r'\s+', ' ', text).strip()` with a two-step normalization:
    1. Normalize horizontal spaces (tabs and consecutive spaces) without touching newlines: `re.sub(r'[^\S\r\n]+', ' ', text)`
    2. Normalize vertical whitespace (excess blank lines) to avoid empty page breaks while preserving paragraph boundaries: `re.sub(r'\n{3,}', '\n\n', text).strip()`
    Ensure both parsers return clean text with preserved line breaks (`\n`) so that `resume_parser.py`'s `lines = text.split('\n')` can properly detect section headers.
  </action>
