<task type="tracer">
  <name>Task 1: Implement Razorpay webhook endpoint with HMAC validation</name>
  <files>server/routes/billing.py</files>
  <action>
    In `server/routes/billing.py`:
    1. Update `POST /api/billing/webhook`:
       - Read raw bytes: `payload = await request.body()`.
       - Read signature header: `signature = request.headers.get("X-Razorpay-Signature")`.
       - Read webhook secret: `secret = os.environ.get("RAZORPAY_WEBHOOK_SECRET")`.
       - Validate HMAC SHA-256: `hmac.new(secret.encode(), payload, hashlib.sha256).hexdigest() == signature`. Reject with 400 if invalid.
       - Parse JSON event:
         - When event is `order.paid` or `payment.captured`:
           - Extract `notes.organization_id` or `notes.user_id`.
           - Update `Subscription` for the organization to `plan="PRO"`, `status="active"`, and extend `current_period_end` by 30 days.
           - Record `Payment` record if not already recorded (idempotency check via `razorpay_payment_id`).
         - When event is `subscription.cancelled` or `payment.failed`:
           - Update `Subscription` to `status="canceled"` or `status="past_due"`.
  </action>
  <verify>
    <automated>python -m py_compile server/routes/billing.py</automated>
  </verify>
  <done>Razorpay webhook handler validates signatures and processes lifecycle events.</done>
</task>
