<objective>
Build the core Fresher-Specific Resume Audit Engine (`server/services/fresher_auditor.py`) to systematically diagnose the exact gaps that cause Indian college students and freshers to get filtered out by campus recruiters and ATS parsers: weak project descriptions lacking metrics, missing GitHub/LinkedIn links, passive phrasing ("worked on"), and formatting traps. Wire the engine into the analysis pipeline and provide automated tests.

Purpose: 0-2 year candidates lack corporate brand names; their resume success depends almost entirely on project depth, link credibility, and action-oriented bullet points. Generic ATS tools miss these domain-specific signals.
Output: Production auditor module, endpoint wiring, and automated pytest suite.
</objective>

<task type="tracer">
  <name>Task 1: Build the 4-pillar Fresher Audit Engine (fresher_auditor.py)</name>
  <files>server/services/fresher_auditor.py, server/utils/resume_parser.py</files>
  <action>
    1. Update `server/utils/resume_parser.py`:
       - Enhance `parse_contact_details` to extract `github`: `r'(?:https?://)?(?:www\.)?github\.com/[a-zA-Z0-9_-]+'`.
       - Add coursework and certifications keywords to `SECTION_HEADERS`:
         - "coursework": ["relevant coursework", "coursework", "core subjects", "key courses", "academic courses"]
         - "certifications": ["certifications", "certificates", "licenses & certifications", "credentials"]
    2. Create `server/services/fresher_auditor.py`:
       - **Pillar 1: Project Quality Checker (`audit_project_quality`)**:
         - Splits project entries.
         - Detects explicit tech stack tags (languages, frameworks, databases, tools: Python, React, Java, Docker, PostgreSQL, etc.). Flags if a project lacks explicit tech keywords.
         - Detects role ownership vs vague group phrasing ("we built", "our team", "was assigned").
         - Detects quantifiable metrics: checks for percentages (`\d+%`), numerals with metric units (`\d+\s*(?:users|ms|s|seconds|queries|stars|downloads|requests|mb|gb|k|m)`), scale or latency statements. Flags *"Missing measurable metric (add users, latency, dataset size, or % gain)"*.
       - **Pillar 2: Missing Sections & Links Auditor (`audit_sections_and_links`)**:
         - GitHub check: Flags missing GitHub as high priority for software/tech freshers.
         - LinkedIn check: Flags missing or malformed LinkedIn.
         - Technical Skills grouping: Checks whether skills are grouped by domain (e.g. "Languages:", "Frameworks:", "Tools:") vs an unorganized single-block dump.
         - Coursework check: Checks for core CS/engineering fundamentals (DSA, Operating Systems, DBMS, Computer Networks, OOP).
         - Education check: Verifies Degree, Graduation Year, and CGPA/Percentage presence.
       - **Pillar 3: Action Verb & Weak Phrase Detector (`detect_action_verbs_and_weak_phrases`)**:
         - Regex scanner detecting passive/weak starters: "worked on", "assisted with", "responsible for", "helped to", "was part of", "handled", "learned", "tried to", "participated in", "contributed to", "involved in", "tasked with".
         - Maps each weak phrase to strong, categorized replacement verbs:
           - Build/Dev: "built", "engineered", "implemented", "developed", "architected"
           - Optimization: "optimized", "streamlined", "accelerated", "scaled", "automated"
           - Leadership/Impact: "spearheaded", "orchestrated", "designed", "benchmarked"
         - Extracts exact line snippets and offsets for interactive replacements.
       - **Pillar 4: ATS 1-Page Layout Validator (`audit_ats_layout_and_formatting`)**:
         - Single-page check: Word count estimation (~350-600 words = 1 page; >650 words flags 2-page risk for 0-2 year graduates).
         - Table / Column formatting risk: Detects table delimiters (`|`, tab alignments) that corrupt parsing flow.
         - Contact professionalism: Checks email handle formatting (flags unprofessional handles) and verifies phone number validity.
         - Section heading recognition: Warns against non-standard headings.
       - **Orchestrator (`run_fresher_audit`)**:
         - Aggregates scores across all 4 pillars into a single `fresher_score` (0-100).
         - Produces a clear `readiness_verdict` ("Campus Placement Ready", "Needs Polish", "High Rejection Risk").
         - Emits `critical_fixes` (top items to fix immediately) and `quick_wins` (fast improvements).
  </action>
