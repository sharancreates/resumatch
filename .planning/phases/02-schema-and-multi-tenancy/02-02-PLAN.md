  <name>Task 1: Implement get_current_organization dependency in server/utils/auth_helper.py</name>
  <files>server/utils/auth_helper.py</files>
  <action>
    In `server/utils/auth_helper.py`, create a dependency `get_current_organization`:
    1. Read optional header `X-Organization-Id` from request headers.
    2. If `X-Organization-Id` is provided:
       - Verify that `user` has an active `Membership` in that organization. If not, raise `HTTPException(403, detail="Not a member of this organization")`.
       - Return a tuple or `TenantContext` containing `(organization, membership)`.
    3. If `X-Organization-Id` is not provided:
       - Query user's default/first membership. If present, return `(organization, membership)`. If user has no memberships, return `(None, None)` or raise 400 where tenant context is mandatory.
    4. Provide helper `require_role(["OWNER", "ADMIN"])` to enforce RBAC rules on sensitive operations.
  </action>
  <verify>
    <automated>python -c "from utils.auth_helper import get_current_organization; print('Dependency defined cleanly')"</automated>
  </verify>
  <done>get_current_organization resolves active organization and validates user membership and role.</done>
</task>
