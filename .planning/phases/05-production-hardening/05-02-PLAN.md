    2. Job 1: `backend-check`:
       - OS: `ubuntu-latest`.
       - Python: `3.11`.
       - Cache: `pip`.
       - Steps:
         - Checkout code.
         - Install backend dependencies: `pip install -r server/requirements.txt`.
         - Python syntax check: `python -m compileall server/`.
         - Alembic migration check: `cd server && python -m alembic heads`.
         - Run tests: `python -m pytest server/tests/ -v`.
    3. Job 2: `frontend-check`:
       - OS: `ubuntu-latest`.
       - Node: `20.x`.
       - Cache: `npm`.
       - Steps:
         - Checkout code.
         - Install client dependencies: `cd client && npm ci`.
         - Lint: `npm run lint`.
         - Unit tests: `npm run test:run` (or Vitest run).
         - Production build: `npm run build`.
  </action>
