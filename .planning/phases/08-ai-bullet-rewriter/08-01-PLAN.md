<task type="tracer">
  <name>Task 1: Build the Grounded AI Bullet Rewriter service (bullet_rewriter.py)</name>
  <files>server/services/bullet_rewriter.py</files>
  <action>
    Create `server/services/bullet_rewriter.py`:
    1. **Anti-Hallucination Prompt Engineering**:
       - Grounding instructions:
         - NEVER invent fake metrics, percentages, dollar amounts, company names, or job titles.
         - When strengthening a bullet, use strong action verbs (built, engineered, optimized) and naturally incorporate the requested target skill keyword.
         - If metric is missing, MUST append an explicit metric insertion placeholder:
           `[Add your metric: e.g. 500+ active users, 35% speedup, 10k dataset size]`.
    2. **Gemini 1.5 Flash Invocation with Robust Fallback**:
       - Uses `GEMINI_API_KEY` with 10s timeout.
       - If `GEMINI_API_KEY` is unset or fails, uses an offline rule-based transformation engine that replaces passive starters with active verbs and adds keyword context + metric placeholder.
    3. **Single Bullet Rewriter Function (`rewrite_single_bullet`)**:
       - Takes `bullet_text`, `target_keyword`, and optional `project_title`.
       - Returns `{"original": str, "rewritten": str, "metric_placeholder": str, "keywords_added": list}`.
    4. **Resume Job Tailoring Function (`tailor_resume_to_job`)**:
       - Takes `resume_text`, `job_text`, `missing_keywords`, and optional `sections`.
       - Identifies weak project bullets and replaces up to 3 bullets with grounded, keyword-enriched rewrites.
       - Reorders or highlights relevant technical skills matching the job description.
       - Preserves candidate contact details and formatting intact.
       - Returns `{"tailored_text": str, "changes_summary": list, "keywords_integrated": list}`.
    5. **Daily LLM Quota Tracker (`check_and_increment_llm_quota`)**:
       - Thread-safe in-memory/cache store tracking `{user_id: {"date": "YYYY-MM-DD", "count": int}}`.
       - Free users: 5 rewrites per day.
       - Premium/Sprint Pass users: 35 rewrites per day.
       - Raises HTTP 429 if exceeded with friendly message.
  </action>

  </verify>
  <done>Grounded bullet rewriter rewrites bullets with strict anti-hallucination guardrails and quota control.</done>
