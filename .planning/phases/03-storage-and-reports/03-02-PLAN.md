<objective>
Extract ReportLab PDF generation into a dedicated service, persist generated evaluations to cloud object storage as Report records, and implement shareable public/restricted report link endpoints.

Purpose: Currently, PDF reports are only generated ephemerally via `GET /history/{id}/export` and streamed without persistence; no `Report` entity is created or saved to object storage.
Output: `report_generator.py` service, `server/routes/reports.py` router with generation and sharing endpoints, and test suite.
</objective>

<task type="auto">
  <name>Task 2: Implement server/routes/reports.py and register in server/app.py</name>
  <files>server/routes/reports.py, server/app.py</files>
  <action>
    1. Create `server/routes/reports.py` with `reports_router = APIRouter(prefix="/api", tags=["reports"])`:
       - `POST /api/reports/generate/{analysis_id}`:
         - Authenticated via `get_current_user`.
         - Validates caller owns analysis or belongs to the resume's organization.
         - Calls `build_ats_report_pdf` to generate PDF bytes.
         - Uploads bytes via `storage.upload_file(pdf_bytes, f"report_{analysis_id}.pdf", "application/pdf")`.
         - Resolves `org_id` from resume or tenant context.
         - Creates `Report(id=str(uuid.uuid4()), organization_id=org_id, name=..., description=..., analysis_ids=[analysis.id], pdf_url=pdf_url)`.
         - Saves and returns `report.to_dict()`.
       - `GET /api/reports/{report_id}`:
         - Retrieves report record.
         - Returns report metadata, PDF download URL, and associated analysis summary.
       - `GET /api/reports/{report_id}/download`:
         - Retrieves report, generates presigned URL or streams PDF bytes via `storage.download_file`.
       - `GET /api/orgs/{org_id}/reports`:
         - Authenticated endpoint verifying user is a member of `org_id`.
         - Returns paginated list of reports for the organization.
       - `DELETE /api/reports/{report_id}`:
         - Restricted to report creator or org `OWNER`/`ADMIN`.
         - Deletes report record and attempts `storage.delete_file(report.pdf_url)`.
    2. In `server/app.py`:
       - Import and register `app.include_router(reports_router)`.
  </action>
  <verify>
    <automated>python -m py_compile server/routes/reports.py server/app.py</automated>
  </verify>
  <done>Persistent report generation and sharing endpoints live and registered in FastAPI.</done>
</task>

| Public / Restricted Report Link | Shareable report links must not expose unauthorized candidate data |
| Org Reports Listing | Reports belonging to one tenant must never be listed or leaked to another tenant |
